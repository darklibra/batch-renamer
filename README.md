# 파일 정리 프로젝트

이 프로젝트는 로컬 폴더에서 파일을 읽고, 파일 이름에서 정보를 추출한 다음, 추출된 정보를 기반으로 파일을 새롭고 정리된 위치로 복사하여 파일을 정리하는 솔루션을 제공합니다.

다음과 같은 **모노레포** 구조로 구성됩니다:
- 파일 스캔, 정보 추출 및 파일 작업을 위한 **Python FastAPI 백엔드**.
- 사용자 상호 작용 및 시각화를 위한 **React 프론트엔드**.

## 주요 기능

- **파일 스캔**: 로컬 디렉토리를 재귀적으로 스캔하여 파일을 찾습니다.
- **정보 추출**: 정의된 패턴을 기반으로 파일 이름에서 구조화된 데이터를 추출합니다.
- **파일 복사**: 추출된 정보를 기반으로 파일을 새 대상으로 복사합니다.
- **API 기반**: 모든 작업을 위한 강력한 API를 백엔드에서 제공합니다.
